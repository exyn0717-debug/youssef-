# ENG YOUSSEF — نسخة الويب 3.2

هذه نسخة_static_ تعمل مباشرة على GitHub Pages أو Vercel بدون خادم Python.

## ما يعمل هنا
- المواد والمحاضرات وبنك الأسئلة والتدريب والملاحظات المحلية.
- معاينة وتنزيل ملفات PDF الأصلية من مجلد `content/library/`.
- الوضع الليلي/النهاري والبحث والتخطيط.

## ما يحتاج خادمًا منفصلًا
- حسابات الطلاب الحقيقية والمزامنة.
- مساعد Claude الحقيقي.

لتشغيل نسخة الخادم كاملة استخدم ملف المشروع الكامل `ENG-YOUSSEF-3.2-Project.zip` على استضافة تدعم Python/FastAPI، واضبط متغيرات البيئة الموضحة في `.env.example` داخل ذلك المشروع.

## الرفع على GitHub من المتصفح
1. افتح المستودع الحالي: `exyn0717-debug/youssef-`.
2. Add file → Upload files.
3. اسحب **محتويات** مجلد `upload-to-github` وليس المجلد نفسه.
4. Commit changes إلى `main`.

إذا كان المستودع مرتبطًا بـ Vercel فسيُنشر تلقائيًا بعد الـ commit. هذه النسخة لا ترفع قاعدة بيانات الطلاب أو أي مفاتيح سرية.
