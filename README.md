# ENG YOUSSEF 3.3

مساحة دراسية عربية RTL مستقلة لطلاب الهندسة — بدون لوحة إدارة أو دليل أعضاء تدريس.

## ما الجديد في 3.3
- تنظيم التكليفات في تبويب مستقل داخل المادة، مع نماذج الإجابة المرفوعة.
- إضافة تجربة قانون هوك ومحاضرتي النهايات والاتصال والمشتقات الأساسية.
- منع تكرار الملفات المتطابقة أو ذات نفس المحتوى، وحفظ الشهادات ذات البيانات الشخصية خارج النشر العام.

## ما الجديد في 3.2
- إزالة الصورة الكبيرة من الرئيسية وتسجيل الدخول، واستبدالها بلوحة «ابدأ من هنا»: محاضرة مقترحة، روابط المواد وبنك الأسئلة والتدريب.
- تنظيم 19 ملف PDF مرفوعًا داخل المواد والمحاضرات المناسبة، مع معاينة PDF وتنزيل الأصلي.
- إضافة بنك نوفمبر LMS لمادة تغيّر المناخ: 130 سؤالًا بالإجابة الأصلية، بدون شروحات مختلقة.
- النسخة المستقلة أصبحت تتضمن ملفات PDF وتعمل معاينتها دون اتصال.

## ما الجديد في 3.1
- هوية بصرية من صورة الشعار الأصلية: أسود/أحمر، مع الوضع الليلي افتراضيًا عند فتح الموقع.
- الوضع النهاري أُعيد تصميمه بألوان فاتحة واضحة، وزر التبديل يحفظ اختيارك.

## ما الجديد في 3.0
- حذف لوحة الإدارة ووظائف تعديل المحتوى ودليل أعضاء التدريس نهائيًا من هذه النسخة.
- ظهور العربي (ARB112) وتغيّر المناخ (ESD217) في الرئيسية والمواد الإضافية.
- منشئ تدريب محسّن: عدد الأسئلة المتاحة يظهر قبل البدء، اختيار المحاضرة، وضع اختبار/تدريب، وقت مخصص.
- مساعد Claude حقيقي عبر Messages API مع محادثات خاصة بالطالب وبث مباشر للرد. يحتاج `ANTHROPIC_API_KEY` على الخادم؛ بدون المفتاح يظهر المساعد كغير مفعّل ولا يخترع إجابات.
- استعادة الحساب برمز استعادة ذاتي بدلاً من إعادة تعيين الإدارة.

## التشغيل
```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export METHOD_PUBLIC_ORIGIN=https://your-domain.example
export METHOD_ALLOWED_ORIGINS=https://your-domain.example
export ANTHROPIC_API_KEY=sk-ant-...   # اختياري لتفعيل Claude
python run.py --host 0.0.0.0 --port 8000
```
للتطوير المحلي فقط: `python run.py --dev`.

## المحتوى
17 مادة، 28 محاضرة/تجربة، 3 تكليفات، 198 سؤالًا، 5 مواد بها محتوى. المحتوى الأصلي محفوظ كما هو؛ المواد الفارغة مساحات صادقة بدون محاضرات أو أسئلة مختلقة.

تفصيل تنظيم الملفات المرفوعة في `LIBRARY.md`.

## النسخة المستقلة
`python tools/build_standalone.py ../ENG-YOUSSEF-3.3-Offline.html`
تحتوي المحتوى والتدريب والملاحظات وملفات PDF دون اتصال. الحسابات والمزامنة وClaude تحتاج الخادم.
